## 学习原则

1. **先理解，再套用。** 说明概念、假设和方法适用的条件。
2. **让数学、统计与代码相互验证。** 尽可能用推导、模拟、数据和图形解释同一个问题。
3. **从小而完整的问题开始。** 一个有问题定义、数据来源、方法、结果解释和局限的小项目，胜过许多只有标题的空目录。
4. **记录可复现过程。** 保存数据来源、关键决策、运行方式和必要的引用；注意隐私与许可。
5. **如实呈现进度。** 规划、进行中和已完成分开记录；只把有证据的成果标为完成。
6. **定期复盘并调整。** 路线服务于学习，不要求按固定速度打卡。

## 当前关注：大一基础

建议先围绕以下基础推进，结合实际课表调整优先级：

- **数据实践：** 在掌握基础后逐步使用 NumPy、pandas 和可视化工具处理小数据集。
- **表达：** 练习用文字、公式、图表和代码讲清一个问题与结论。
